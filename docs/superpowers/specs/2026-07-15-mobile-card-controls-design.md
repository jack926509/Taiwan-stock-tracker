# 手機版自選股卡片操作控制設計

## 目標

修正自選股卡片的拖曳把手與刪除按鈕浮出卡片、遮住股票名稱或被螢幕邊緣裁切的問題，讓手機版保持乾淨、易讀且不易誤觸。

## 設計決策

採用低干擾的響應式控制方式：

- 手機版的拖曳把手收進卡片左側，保留至少 44 × 44 px 的觸控範圍，但只顯示小型六點圖示。
- 卡片內容必須為拖曳把手保留固定空間，股票名稱、代號與價格都不得被遮住。
- 手機版不顯示獨立的刪除 `X`，沿用現有的左滑刪除操作，避免畫面雜亂與誤觸。
- 桌面版保留刪除按鈕，但按鈕必須完整位於卡片右上角內側，並只在滑鼠移入或鍵盤聚焦時顯示。
- 拖曳與刪除控制均不得使用會超出卡片邊界的負向定位。

## 元件調整

### `SortableCard`

- 保留現有 `dnd-kit` 排序行為與 44 × 44 px 手機觸控目標。
- 將把手定位改為卡片左側內部，不再使用負向 `left` 或 `top`。
- 只在卡片可排序時預留左側空間；不可排序或篩選中的卡片維持原本版面。

### `QuoteCard`

- 增加可由外層指定的左側控制安全區，讓可排序卡片的標題與代號避開拖曳把手。
- 刪除按鈕在手機斷點隱藏，在桌面斷點顯示於卡片內右上角。
- 不改變卡片連結、報價、走勢圖、成交量與刪除資料流程。

### `app/page.tsx`

- 僅在目前允許拖曳排序的條件下，對卡片啟用左側控制安全區。
- 保留 `SwipeToDelete`，手機刪除流程仍由左滑觸發。

## 互動與無障礙

- 拖曳把手維持 `aria-label="拖曳排序"`，並支援觸控、滑鼠與鍵盤操作。
- 桌面刪除按鈕維持包含股票名稱的無障礙標籤。
- 觸控控制尺寸至少 44 × 44 px；視覺圖示可較小，但可點擊範圍不可縮小。
- 焦點狀態必須清楚可見，不能依賴滑鼠 hover 才能操作。

## 驗收標準

- 390 px 寬手機畫面中，拖曳把手完整位於卡片內且不遮住股票名稱或代號。
- 手機畫面不顯示刪除 `X`，左滑仍可啟動刪除操作。
- 桌面畫面中的刪除按鈕完整位於卡片內，不會被卡片或瀏覽器邊界裁切。
- 預設排序可拖曳；非預設排序、篩選狀態或只有一檔股票時，不出現多餘的拖曳安全區。
- 現有報價、搜尋、篩選、排序、離線快取與 PWA 行為不受影響。
- `npm test`、`npm run build` 與 `npm run smoke` 全部通過，並實際以手機尺寸開啟頁面確認渲染。

## 不在本次範圍

- 不新增編輯模式。
- 不更換卡片色彩、字體、報價資料或走勢圖。
- 不修改後端 API、Zeabur 服務或資料庫。
