# 手機版自選股首頁重設計規格

日期：2026-07-14（Asia/Taipei）
狀態：使用者已選定 A「資訊卡片型」視覺方向

## 目標

將手機版首頁調整成適合每日快速看盤的自選股介面。使用者打開 PWA 後，應能在首屏確認市場狀態、搜尋股票，並一眼辨識自選股的成交價、漲跌方向、漲跌幅與資料新鮮度。

桌面版、後端 API、資料庫、股票資料格式及個股詳情頁不在本次重設計範圍。

## 已確認方向

採用 A「資訊卡片型」：

- 延續目前暖米色、墨綠、紅綠行情色的品牌風格。
- 每檔股票使用單欄卡片，手機首屏可見約 2 至 3 檔。
- 股票名稱與代號在左側；成交價與漲跌幅在右側，形成固定掃視路徑。
- 資料時間、成交量、訊號與提醒屬次要資訊，降低視覺權重。
- 底部維持「自選／搜尋／提醒」三分頁導覽。

## 手機版資訊架構

由上而下排列：

1. 頂部狀態列：站名、台北日期時間、盤中／已收盤狀態及手動更新按鈕。
2. 股票搜尋列：可搜尋代號或名稱，點擊結果後沿用既有新增流程。
3. 離線或資料異常提示：只在離線、快取或更新錯誤時出現。
4. 自選股工具列：顯示股票數量，提供篩選、排序與拖曳排序狀態。
5. 自選股卡片清單：手機單欄，桌面版維持既有多欄格線。
6. 新增股票區與資料來源說明。
7. 手機底部固定導覽。

## 頂部與搜尋

- 手機頂部壓縮為兩層：第一層顯示站名及盤別，第二層顯示日期時間與更新狀態。
- 更新按鈕保留至少 44 × 44 CSS px 的觸控範圍，更新中提供可辨識狀態。
- 搜尋列在手機版移至自選股清單上方，視覺上是首頁的主要輸入入口。
- 桌面版仍沿用現有 masthead 與搜尋配置，不因手機版調整而退化。

## 自選股卡片

每張手機卡片必須包含：

- 股票名稱與代號。
- 成交價。
- 漲跌金額與漲跌幅。
- 報價時間。
- 成交量。

可選資料依既有資料狀態顯示：

- 迷你走勢圖。
- 技術訊號。
- 已設定的到價提醒。
- 快取或資料延遲標記。

互動規則：

- 點擊卡片進入個股詳情頁。
- 預設排序下保留拖曳排序；手機以拖曳把手或明確區域啟動，避免與卡片點擊、左右滑動刪除衝突。
- 左滑超過既有門檻後沿用目前的刪除行為；滑動期間必須清楚露出紅色「刪除」底層，避免誤解操作結果。
- 漲跌顏色不是唯一提示，必須同時顯示正負號、箭頭或文字。

## 排序與篩選

- 現有「預設／漲幅／跌幅」排序及「全部／已設提醒／僅看漲／僅看跌」篩選保留。
- 手機版以水平可捲動的膠囊按鈕呈現，避免壓縮文字。
- 非預設排序時停用拖曳排序，並清楚顯示目前排序方式。
- 切換排序或篩選不重新載入整頁。

## 離線與資料更新

- 離線提示置於搜尋列與自選股工具列之間。
- 提示文字必須說明目前顯示最後一次快取資料，並顯示可取得的快取時間。
- API 快取維持 15 分鐘上限；超過時效不再把舊資料視為可用即時報價。
- 瀏覽器恢復連線後，首頁自動重新驗證自選清單、即時報價及迷你走勢資料。
- 自動更新失敗時保留目前畫面，顯示可理解的重試提示，不清空已載入的卡片。

## 響應式與 PWA

- 主要設計寬度為 360 至 430 CSS px。
- 手機卡片採單欄；`sm` 以上沿用既有雙欄、桌面多欄規則。
- 遵守 iPhone 頂部與底部安全區域。
- 底部導覽固定於視窗，不得隨內容滾動離開。
- 安裝提示不得遮住底部導覽或主要操作。
- 最小互動目標為 44 × 44 CSS px，支援鍵盤焦點與可辨識的 focus 樣式。

## 元件邊界

- `app/page.tsx`：首頁資料狀態、排序、篩選與版面組合。
- `components/QuoteCard.tsx`：自選股卡片的手機資訊層級與桌面相容樣式。
- `components/DraggableGrid.tsx`、`components/SortableCard.tsx`：拖曳排序與觸控衝突處理。
- `components/MobileNetworkBanner.tsx`：離線、快取與重試提示。
- `components/BottomNav.tsx`：手機底部固定導覽與提醒數量。
- `app/globals.css`、`tailwind.config.ts`：只加入此設計必要的樣式，不做無關重構。

現有 `app/globals.css`、`app/layout.tsx`、圖表與 Tailwind 設定已有未提交修改。實作時必須逐段比對，只修改與本規格直接相關的內容，不覆蓋其他變更。

## 錯誤與空狀態

- 尚未加入自選股：顯示單一主要動作，引導搜尋或加入第一檔股票。
- 自選清單成功但報價失敗：保留股票名稱與代號，價格區顯示更新失敗狀態。
- 部分股票無報價：只影響該卡片，不阻斷整個清單。
- 排序儲存失敗：保留當次樂觀排序，下一次資料同步時校正，並提供非阻斷提示。
- 離線且沒有快取：顯示介面與空資料說明，不顯示假價格。

## 驗收標準

1. 在 390 × 844 CSS px 的手機視窗中，首頁首屏可看到頂部狀態、搜尋列及至少兩張自選股卡片的主要行情資訊。
2. 名稱、代號、價格、漲跌幅、成交量與報價時間在手機卡片上不重疊、不截斷核心數值。
3. 排序、篩選、拖曳、卡片導向、滑動刪除與下拉更新維持可用。
4. 離線時介面仍可開啟，資料清楚標示為快取；恢復連線後自動更新。
5. 底部導覽、PWA 安裝提示與 iPhone 安全區域互不遮擋。
6. 桌面版既有多欄首頁不退化。
7. `npm test`、`npm run build` 與 `npm --prefix frontend run build` 全數通過。
8. 使用實際瀏覽器驗證手機尺寸、桌面尺寸、離線重載及恢復連線狀態。

## 不納入範圍

- 不修改 Zeabur 後端、Supabase 結構或 Cloudflare API 代理。
- 不新增交易、下單、投資組合損益或新的技術分析功能。
- 不全面重設個股詳情、搜尋、提醒或桌面版。
- 本階段不推送 GitHub 或部署 Cloudflare；完成驗證後另行取得發布確認。
