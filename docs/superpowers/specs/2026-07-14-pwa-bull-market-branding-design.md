# PWA 精品牛市封面設計

## 目標

將目前以「台」字為主的 PWA 圖示，改成使用者核准的 A「精品牛市」方向。手機桌面圖示與啟動畫面應使用同一套視覺，讓人一眼看出是台股工具，同時呈現明確的牛市上升動能。

## 核准的視覺方向

- 背景：目前品牌使用的暖米白色。
- 主體：深藍色圓角方形圖章，不使用「台」字或其他單字標誌。
- 圖形：五根由左下往右上排列的台股紅色 K 棒，搭配一條低調的金色上升趨勢線。
- 氣質：乾淨、成熟、有投資工具的可信度，不做霓虹交易終端風格。
- 文字：App icon 不放文字；啟動畫面在圖形下方顯示「台股追蹤」，不加入英文副標。
- 禁止項目：牛隻插畫、人物、硬幣、鈔票、火箭、浮誇 3D、漸層字、浮水印。

## 輸出資產

1. 一張高解析度方形主圖，作為所有 App icon 的唯一來源。
2. 192×192 與 512×512 一般 PWA icon。
3. 512×512 maskable icon，重要圖形保持在中央安全區，避免 Android 裁切。
4. Apple touch icon。
5. iPhone 直式啟動畫面：由同一主圖與米白背景生成 750×1334、828×1792、1125×2436、1170×2532、1179×2556、1206×2622、1242×2688、1290×2796、1320×2868；畫面中央為圖形，下方為「台股追蹤」。

所有衍生尺寸都由同一張核准主圖產生，避免不同裝置出現不同版本的 K 棒。

## 專案整合

- PWA manifest 改指向新的實體 icon 資產，保留 `standalone`、直式方向與現有主題色。
- Next.js metadata 更新一般 icon、Apple touch icon 與 Apple startup image 連結。
- Service Worker 的 App Shell 清單加入新圖示與啟動畫面；提高快取版本，避免已安裝裝置繼續使用舊圖。
- 不修改首頁功能、股票資料、Zeabur API 代理或離線資料標示邏輯。

## 驗收標準

- App icon 在 192×192 尺寸仍能清楚辨識向右上排列的紅色 K 棒。
- Android maskable 裁切後，K 棒與金色趨勢線沒有被切掉。
- iPhone 加入主畫面後使用新 icon，從主畫面開啟時顯示同風格米白啟動畫面。
- `manifest.webmanifest`、icon、Apple startup image 與 `sw.js` 在正式網域皆回應 HTTP 200。
- `npm test`、主專案 build 與 `frontend` build 全部通過。
- 以手機寬度實際開啟正式網站，首頁正常渲染且瀏覽器 console 無錯誤。

## 發布方式

只提交本功能相關檔案，不納入工作區既有的其他未提交修改。完成驗收後推送目前功能分支，建立 PR 合併至 `main`，由 Cloudflare Pages 的 GitHub 整合自動部署至 `https://twstock.xiehnet.com`。
