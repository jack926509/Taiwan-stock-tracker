# 休市行情與興櫃報價修正

使用者於 2026-10-17 確認依診斷建議修正休市日期判斷、缺價計數、興櫃辨識與報價支援。本次只實作與本機驗收，正式發布另依專案授權流程。

## 驗收條件

- 週末、官方休市日及交易日 09:00 前，以最近已開始交易的交易日檢查畫面行情；09:00 起要求當日。日期未知、未來時間及更舊的行情仍有警示。
- 缺少有效價格的股票單獨計數；日期／時間異常另計。指數缺漏仍使整批 `complete=false`，不能因自選股都有價就假報完整。
- 官方興櫃名冊辨識為 `emerging`，搜尋、首頁、個股及提醒頁顯示「興櫃」。既有錯標上櫃的自選股在讀取時校正，不直接修改正式資料庫、不刪除自選股或提醒設定。
- 興櫃使用櫃買中心官方最新行情統計，來源與製表時間清楚標示，僅供參考。前日均價不能填成昨收價；未知開盤價與漲跌保持未知；成交量需有官方股數證據才換算為張。
- 混合來源逐檔保留來源，整批標為混合來源；來源失敗仍回報實際缺漏，不影響已取得的其他市場行情。
- 興櫃參考行情不觸發即時 LINE 提醒，不開放新增或重新啟用興櫃提醒。既有條件保留；一般上市／上櫃提醒仍需完整 MIS 批次、實際成交、台北當日時間及 120 秒新鮮度。收盤 LINE 仍維持完整 MIS 當日資料限制。

## 方案

共用 `Market` 加入興櫃，新增官方名冊與報價 provider，沿用現有 MIS／Yahoo／舊快照流程處理上市上櫃。以官方名冊校正市場，不用 Yahoo `.TWO` 推斷興櫃／上櫃。讀取校正只作用於回傳值，名稱、排序、分組、提醒不變。

日期判斷只供顯示，由 API 回傳 `expectedQuoteDate`；不改動排程或 LINE 的日期檢查。首頁缺價與時間異常分組顯示，保留整批完整性契約。
