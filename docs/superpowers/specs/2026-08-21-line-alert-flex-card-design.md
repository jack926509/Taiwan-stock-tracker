# LINE 到價提醒精簡 Flex 卡片設計

## 目標

將現有四種到價通知由純文字訊息改為 LINE Flex 卡片。卡片採用使用者確認的 B 方案：資訊精簡、單一白底卡片、依提醒語意使用色彩，並提供前往個股頁的按鈕。每日收盤總結維持既有深藍完整卡片，不在本次範圍。

## 範圍與呈現

四種提醒共用同一個卡片骨架：漲破價、跌破價、漲跌幅與爆量。標題顯示提醒類型與台北時間；內容依序顯示股票名稱與代號、現價與當日漲跌幅、觸發原因、以及三項必要行情資料；底部按鈕連至該股票頁。

- 漲破價與正向漲跌幅：紅色語意。
- 跌破價與負向漲跌幅：綠色語意。
- 爆量：中性色標題，保留成交量與近五日均量倍數作為觸發原因。
- 每一張 Flex 訊息都保留 400 字以內的純文字 `altText`，供 LINE 預覽與不支援 Flex 的讀取情境使用。

## 實作邊界

`lib/alerts.ts` 負責判斷條件並提供卡片所需資料；新增的小型純函式模組只負責組裝 `LineMessage`，不讀取環境變數、不存取 Supabase、不呼叫 LINE API。既有 `pushLineMessages()`、每日上限、失敗紀錄，以及「LINE 成功後才標記提醒已觸發」的語意保持不變。

## 驗收

測試涵蓋四種提醒，驗證各自的 Flex `altText`、標題、語意色、觸發原因與個股連結。完整專案測試、型別檢查、Next.js build、OpenNext Worker build 與 bundle dry-run 均須通過。由於使用者未授權再次對外發送，完成後不另送 LINE 訊息、不上傳預覽版與不部署。
