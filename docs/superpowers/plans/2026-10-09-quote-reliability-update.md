# 報價可靠性與專案更新

使用者已授權依 2026-10-08 查看結果，優化與更新本地專案。保留現有修改及暫存檔案；不推送正式分支、不部署、不操作正式資料庫或發送 LINE。

## 驗收條件

- 證交所暫時失敗後，在固定等待時間結束時能重新嘗試，不因持續輪詢延長等待。
- Yahoo 備援與舊快照顯示來源、資料日期及缺漏狀態；缺少股票時不標示完整。
- LINE 提醒僅使用證交所即時報價，Yahoo 備援及舊快照不觸發通知。
- Yahoo 成交量經來源確認並對齊「張」；無法確認的數值顯示未知。
- 首頁、搜尋、提醒、個股頁在桌面及 390 × 844 手機尺寸正常顯示；缺漏、備援及操作失敗有明確回饋。
- README 與 CLAUDE 對齊根目錄 OpenNext Worker、Supabase 及 main 推送自動部署；暫存資料不納入版本控制。
- 單元／整合測試、型別檢查、Next.js 建置、OpenNext 建置、Worker dry-run 及本機預覽檢查通過，並完成獨立審查。

## 執行順序

1. 備份目前差異，建立本地修正分支，整合 origin/main。
2. 透過 fetchQuotes／fetchYahooQuotes 的外部介面補行為測試，修正重試、快取時間、完整性及來源解析。
3. 透過 checkAlerts 補通知測試，更新畫面對備援／缺漏的提示及相關操作回饋。
4. 確認相依套件安全狀態，執行必要的相容性更新；同步文件與忽略規則。
5. 執行專案驗收，使用隔離資料與本機預覽避免影響正式資料及通知。
6. 獨立審查修正及驗收證據，保留本地提交並交付可查看的結果；正式推送另待使用者確認。
