# 首頁收盤回顧與系統狀態優化

日期：2026-10-17（台北）

## 範圍與驗收

依使用者截圖，沿用暖米白風格，縮短收盤回顧與系統狀態卡片，讓常用資訊先出現，說明與技術細節可展開閱讀。這次僅本機實作、驗收及提交，未授權推送或部署。

- 收盤回顧預設開啟最近一筆真正保存的快照；可指定日期、回到最近一筆及查看今天。
- 指定日期無紀錄、完全沒有紀錄、讀取失敗與今日未保存暫覽分開呈現；不以其他日期行情填充歷史。
- 快照的來源、保存時間、缺漏與原始內容仍可辨識；既有歷史不覆寫。
- 系統狀態先呈現上次檢查時間與結果，避免將上次成功寫成目前持續運作。
- LINE、K 線與備份說明可展開；匯出備份、重新讀取及提醒頁每檔結果仍可直接操作／閱讀。
- 失敗、資料缺漏及讀取舊資料提示不得藏在展開區內。
- 桌面與 390 × 844 手機可閱讀及操作，無橫向溢出或 console error。

## 實作順序

1. 以既有個人紀錄儲存介面增加唯讀最近快照查詢，先測試排序、空結果與錯誤。
2. 收盤回顧採最近快照預設模式，簡化查詢列與說明，保留指定日期的使用者選擇。
3. 系統狀態改為重點摘要與詳細資訊，保留可見異常及備份功能。
4. 跑專案完整驗收指令，使用無正式憑證的記憶體假資料庫驗證 Worker API、桌機／手機與日期切換、展開、重新讀取、備份。
5. 交給 fresh-context 審查者檢查 diff 與實跑測試；修正後記錄證據並本機提交。

## 限制

不新增正式資料表、不更改排程與通知門檻、不回填收盤歷史、不操作正式資料或發送 LINE。日期以 Asia/Taipei 解釋。介面採用現有原生表單及 details，無新增動畫、字型或套件。
