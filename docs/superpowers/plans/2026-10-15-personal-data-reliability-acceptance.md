- 首次載入時，自選清單可能比報價先回來，因此短暫顯示「報價暫缺」，頂部仍顯示載入中；審查列為非阻擋的文案改善。
- 行事曆來源無法取得時，仍沿用既有週間判斷；不能因此保證臨時休市日一定判定正確。
- 本次不變更提醒規則、通知發送與排程，也未驗證正式 LINE 發送；下一版再處理提醒歷史與實際監控狀態。

## 重現本機畫面

在已完成 `cf:build` 的前提下，啟動本機 Worker 與隔離代理：

```bash
npm run cf:preview -- --port 8787 --ip 127.0.0.1
node scripts/personal-preview-fixtures.mjs http://127.0.0.1:8787
```

- `http://127.0.0.1:8790`：部分缺報價、基本面保留舊資料。
- `http://127.0.0.1:8791`：全部報價失敗。
- `http://127.0.0.1:8792/stock/2330`：基本面全部暫時無法取得。

測試畫面可查看與切換；儲存、新增、刪除等操作會被隔離代理封鎖。
